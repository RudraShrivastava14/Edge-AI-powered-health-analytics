# Edge Configuration

| File | Committed? | Purpose |
|---|---|---|
| `device.example.yaml` | yes | Template for per-device settings |
| `device.yaml` | **no** (gitignored) | Actual local settings |
| `certs/<deviceId>/` | **NEVER** (gitignored) | X.509 certificate, private key, Amazon root CA |

Certificates are generated by `infrastructure/scripts/provision_device.sh`. If one is ever
committed, revoke it in AWS IoT immediately — deleting the commit is not enough.
